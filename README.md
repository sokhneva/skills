# Навыки для Claude Code

Два навыка, которые заставляют Claude Code думать до того, как он начнёт делать.

- **`/plan`** — разбирает задачу перед стартом: что именно делаем, где границы, какими
  двумя-тремя способами это можно решить и чем они отличаются. На выходе — файл с планом:
  требования, шаги, и у каждого шага проверка, по которой видно, что он правда сделан.
  План живёт в файле, поэтому его переживает и закрытая вкладка, и потерянный контекст.
- **`/defend`** — собирает панель враждебных стейкхолдеров и бьёт по вашему кейсу или плану:
  финдир спрашивает про деньги, техдир про сроки и зависимости, скептик про «почему сейчас»,
  аналитик про источники цифр. Хвалить ему запрещено. В конце выдаёт карту защиты: пять
  самых опасных вопросов и лучшие версии ответов.

Навыки — это обычные текстовые файлы. Их можно открыть, прочитать и переписать под себя.

## Что нужно

[Claude Code](https://claude.com/claude-code) — приложение или расширение от Anthropic.
Если он у вас уже стоит, всё остальное занимает пять минут. Больше ничего ставить не надо:
ни Python, ни ключей, ни сторонних сервисов.

## Как поставить

### Шаг 1. Скачать файлы

Нажмите зелёную кнопку **Code** вверху этой страницы → **Download ZIP**. Распакуйте архив
двойным щелчком — получится папка `skills-main`. Откройте её: внутри лежит папка `skills`,
а в ней две — `plan` и `defend`. Дальше нужны именно эти две.

### Шаг 2. Положить папки на место

Claude Code ищет навыки в папке `.claude/skills` в вашем домашнем каталоге.

**На Mac.** Откройте Finder, нажмите `Cmd + Shift + G`, вставьте строку и нажмите Enter:

```
~/.claude/skills
```

Папка начинается с точки, поэтому в Finder обычным способом она не видна — это нормально.
Если по этому пути ничего нет, создайте папку `skills` внутри `.claude` руками.

**На Windows.** В проводнике вставьте в адресную строку:

```
%USERPROFILE%\.claude\skills
```

Теперь перетащите туда обе папки — `plan` и `defend`. Должно получиться так:

```
.claude/skills/plan/SKILL.md
.claude/skills/plan/references/research-agents.md
.claude/skills/plan/templates/plan-template.md
.claude/skills/defend/SKILL.md
```

Кто дружит с терминалом — то же самое одной командой:

```bash
git clone https://github.com/sokhneva/skills.git
mkdir -p ~/.claude/skills && cp -r skills/skills/* ~/.claude/skills/
```

### Шаг 3. Перезапустить Claude Code

Закройте и откройте заново. Навыки подхватываются при старте.

## Как пользоваться

Можно вызвать командой:

```
/plan переделать лендинг под мобильные
```

А можно просто сказать словами — Claude сам поймёт, что пора планировать:

> Давай переделаем лендинг под мобильные, с чего начать

Когда план готов, он предложит прогнать его на дыры:

```
/defend docs/plans/2026-08-14-lending.md
```

`/defend` работает и по кейсу — презентации, стратегии, любому документу, который вам
предстоит защищать:

```
/defend материалы-к-защите.md
```

## Если не сработало

- **Claude не видит навык.** Проверьте, что перезапустили приложение и что путь именно
  `.claude/skills/plan/SKILL.md`, а не `.claude/skills/skills/plan/SKILL.md` — при
  распаковке легко получить лишний уровень вложенности.
- **Хочется положить навык только в один проект, а не на весь компьютер.** Создайте папку
  `.claude/skills` внутри папки проекта и положите туда же. Тогда навык работает только
  в этом проекте.
- **Не нравится, как навык себя ведёт.** Откройте `SKILL.md` и перепишите. Это простой
  текст с инструкциями, никакого кода внутри нет.

## Откуда это

`/plan` собран по мотивам статьи Мэтта Ван Хорна «Все хаки агентного инжиниринга» и механик
Compound Engineering, superpowers и spec-kit. `/defend` — своя разработка, выросла
из подготовки к защитам продуктовых кейсов.

Оба навыка — рабочие копии из личной системы, обезличенные для публикации. Забирайте,
переделывайте под себя, ссылка на источник не требуется.
